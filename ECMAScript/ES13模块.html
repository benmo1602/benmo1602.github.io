ES13 (2022) 模块 ​

ECMAScript 2022 (ES13) 于 2022 年 6 月正式发布。本次更新主要聚焦于类 (Class) 功能的完善，使其更接近传统面向对象语言的开发体验，同时也引入了一些极其实用的语法糖和 API 增强。

发布内容 (Released Features) ​

以下是 ES2022 正式包含的新特性：

1. 类功能的重大增强 (Class Features) ​

ES13 彻底改变了我们在 JavaScript 中编写类的方式，大大简化了代码并增强了封装性。

公有实例字段 (Public Instance Fields) ​

不再需要在构造函数 (constructor) 中定义属性。现在可以直接在类的主体中声明实例字段。

javascript
class User {
  // 直接定义属性，代码更清晰
  name = 'Anonymous';
  role = 'Guest';

  constructor(name) {
    if (name) {
      this.name = name; // 可选的覆盖逻辑
    }
  }
}

const user = new User('Alice');
console.log(user.name); // Alice

私有实例字段与方法 (Private Class Features) ​

使用 # 前缀可以将字段、方法或访问器标记为私有。私有成员只能在类内部访问，从外部访问会报错，实现了真正的封装。

javascript
class Counter {
  #count = 0; // 私有字段

  #increment() { // 私有方法
    this.#count++;
  }

  tick() {
    this.#increment();
    return this.#count;
  }
}

const c = new Counter();
console.log(c.tick()); // 1
// console.log(c.#count); // SyntaxError: Private field '#count' must be declared in an enclosing class

静态块 (Static Initialization Blocks) ​

允许在类中定义 static {} 代码块，用于执行复杂的静态属性初始化逻辑（例如包含 try...catch）。

javascript
class Config {
  static API_URL;

  static {
    try {
      const isProd = process.env.NODE_ENV === 'production';
      this.API_URL = isProd ? 'https://api.prod.com' : 'http://localhost:3000';
    } catch {
      this.API_URL = 'http://localhost:3000';
    }
  }
}

2. 顶层 await (Top-level await) ​

现在可以在模块的最外层直接使用 await 关键字，而无需将其包裹在 async 函数中。这让模块的初始化（如加载配置、连接数据库）变得非常直观。

javascript
// db-connection.js
const connection = await connectToDatabase();
export default connection;

// main.js
// 导入该模块时，会等待连接建立完成后再继续执行
import db from './db-connection.js';

3. at() 方法 ​

数组 (Array)、字符串 (String) 和类型数组 (TypedArray) 新增了 at() 方法，支持使用负整数从末尾索引元素。

javascript
const list = ['apple', 'banana', 'orange'];

// 旧写法
const lastItem = list[list.length - 1];

// 新写法
const lastItemNew = list.at(-1); // 'orange'
const secondLast = list.at(-2);  // 'banana'

4. Object.hasOwn() ​

这是一个更安全、更便捷的方法来检查对象是否拥有某个自有属性（Own Property）。它旨在替代 Object.prototype.hasOwnProperty.call(obj, 'key')。

javascript
const obj = Object.create(null); // 创建一个没有原型的对象
obj.prop = 'exists';

// obj.hasOwnProperty('prop'); // 报错：obj.hasOwnProperty is not a function

console.log(Object.hasOwn(obj, 'prop')); // true

5. Error Cause (错误原因) ​

在抛出错误时，可以传入一个 cause 属性，用来串联错误链。这在捕获底层错误并抛出更高级别业务错误时非常有帮助，因为它保留了原始错误的堆栈信息。

javascript
async function loadData() {
  try {
    await fetchApi();
  } catch (err) {
    // 抛出新错误，同时附带原始错误作为原因
    throw new Error('数据加载失败', { cause: err });
  }
}

try {
  await loadData();
} catch (e) {
  console.log(e.message); // "数据加载失败"
  console.log(e.cause);   // Error: fetchApi failed (原始错误信息)
}

6. 正则表达式匹配索引 (/d flag) ​

正则表达式新增了 d 标志。启用后，匹配结果对象会包含一个 indices 属性，其中记录了每个捕获组在原字符串中的开始和结束索引。

javascript
const regex = /a(b)c/d;
const match = regex.exec('abc');

console.log(match.indices[0]); // [0, 3] (整个匹配 'abc' 的范围)
console.log(match.indices[1]); // [1, 2] (捕获组 'b' 的范围)
