ES15 模块 (ES2024) ​

ECMAScript 2024 (ES15) 是 JavaScript 语言的最新标准版本，于 2024 年 6 月正式发布。本次更新带来了一些实用的新特性，主要集中在数据分组、Promise 处理、字符串处理以及内存管理等方面。

发布内容 (Released Features) ​

以下是 ES2024 正式包含的新特性：

1. Object.groupBy 和 Map.groupBy ​

这是本次更新中最受关注的特性之一。它提供了原生的静态方法来对数组或可迭代对象进行分组，取代了以往需要使用 reduce 或第三方库（如 Lodash）的场景。

注意：由于 Web 兼容性问题，原提案中的 Array.prototype.groupBy 被修改为静态方法 Object.groupBy。

Object.groupBy ​

返回一个普通对象，键为字符串。

javascript
const items = [
  { name: '芦笋', type: 'vegetable' },
  { name: '香蕉', type: 'fruit' },
  { name: '山羊', type: 'meat' },
  { name: '樱桃', type: 'fruit' },
  { name: '鱼', type: 'meat' }
];

const result = Object.groupBy(items, ({ type }) => type);

/* 结果:
{
  vegetable: [{ name: '芦笋', type: 'vegetable' }],
  fruit: [{ name: '香蕉', type: 'fruit' }, { name: '樱桃', type: 'fruit' }],
  meat: [{ name: '山羊', type: 'meat' }, { name: '鱼', type: 'meat' }]
}
*/

Map.groupBy ​

返回一个 Map 对象，键可以是任何类型（对象、数字等），更加灵活。

javascript
const inventory = [
  { name: 'asparagus', quantity: 10 },
  { name: 'bananas', quantity: 5 },
  { name: 'goat', quantity: 23 },
  { name: 'cherries', quantity: 5 },
  { name: 'fish', quantity: 22 }
];

const result = Map.groupBy(inventory, ({ quantity }) => quantity);

/* 结果 (Map):
Map(3) {
  10 => [{ name: 'asparagus', quantity: 10 }],
  5 => [{ name: 'bananas', quantity: 5 }, { name: 'cherries', quantity: 5 }],
  23 => [{ name: 'goat', quantity: 23 }],
  22 => [{ name: 'fish', quantity: 22 }]
}
*/

2. Promise.withResolvers ​

这是一个便捷的工厂方法，用于创建一个新的 Promise，并同时返回用于解决（resolve）或拒绝（reject）该 Promise 的函数。这在需要从外部控制 Promise 状态的场景中非常有用，避免了以往繁琐的封装写法。

javascript
// 旧写法
let resolve, reject;
const promise = new Promise((res, rej) => {
  resolve = res;
  reject = rej;
});

// ES2024 新写法
const { promise, resolve, reject } = Promise.withResolvers();

// 使用示例
setTimeout(() => resolve('成功！'), 1000);

3. 字符串格式良好性 (Well-Formed Unicode Strings) ​

新增了两个方法来处理 Unicode 字符串中的“孤立代理对”（Lone Surrogates），这在处理用户输入或网络数据时非常有用，可以避免 URI 编码错误。

  • String.prototype.isWellFormed(): 检查字符串是否包含孤立代理项。
  • String.prototype.toWellFormed(): 将包含孤立代理项的字符串转换为格式良好的字符串（用 U+FFFD 替换）。
javascript
const s = "ab\uD800"; // \uD800 是一个孤立的前导代理

console.log(s.isWellFormed()); // false

const wellFormed = s.toWellFormed();
console.log(wellFormed); // "ab"
console.log(wellFormed.isWellFormed()); // true

4. 正则表达式 v 标志 (RegExp v flag) ​

v 标志是 u (unicode) 标志的升级版，提供了更强大的 Unicode 支持，特别是集合表示法 (Set Notation) 和属性类 (Properties of Strings)。

javascript
// 集合差集：匹配是希腊字母但不是 'π' 的字符
const re = /[\p{Script_Extensions=Greek}--π]/v;

// 集合交集：匹配即是 ASCII 又是数字的字符
const re2 = /[\p{ASCII}&&\p{Number}]/v;

console.log(re2.test('5')); // true
console.log(re2.test('a')); // false

5. Atomics.waitAsync ​

Atomics.wait 的异步版本。它允许在主线程（不允许阻塞的线程）中等待共享内存的变化，而不会阻塞 UI。它返回一个 Promise。

javascript
const sab = new SharedArrayBuffer(1024);
const int32 = new Int32Array(sab);

// 在非阻塞线程中等待索引 0 的值变为非 0
const result = Atomics.waitAsync(int32, 0, 0);
// { async: true, value: Promise { <pending> } }

6. 可调整大小的 ArrayBuffer (Resizable ArrayBuffer) ​

允许创建长度可变的 ArrayBuffer，以及相关的 transfer 方法来转移内存所有权，提高内存管理效率。

javascript
const buffer = new ArrayBuffer(100, { maxByteLength: 1000 });
console.log(buffer.resizable); // true

buffer.resize(200);
console.log(buffer.byteLength); // 200

// 转移所有权（零拷贝）
const newBuffer = buffer.transfer();
console.log(buffer.detached); // true
console.log(newBuffer.byteLength); // 200

采纳内容 (Adopted Content) ​

这些特性在 2023 年至 2024 年期间通过了 TC39 的完整标准化流程（Stage 4），并被正式纳入 ECMA-262 标准。

  • 流程：所有特性都经历了从 Stage 0 (Strawperson) 到 Stage 4 (Finished) 的严格审查。
  • 标准：上述功能已成为 Web 标准的一部分，现代浏览器（Chrome, Firefox, Safari, Edge）和 Node.js 最新版本均已支持。

草案内容 (Draft Proposals) ​

以下是一些目前处于活跃状态（Stage 3），虽然未包含在 ES2024 中，但有望在未来版本（ES2025+）中加入的重要提案：

1. Temporal (Stage 3) ​

旨在彻底解决 JS 中 Date 对象的各种痛点，提供现代、易用且不可变的日期时间 API。

javascript
// 未来用法预览
const now = Temporal.Now.plainDateTimeISO();
const date = Temporal.PlainDate.from('2025-01-01');

2. Decorators (装饰器) (Stage 3) ​

为类和类成员提供元编程能力的语法，已被 TypeScript 广泛使用，标准化后将原生支持。

javascript
@defineElement('my-class')
class MyClass extends HTMLElement { ... }

3. Pipeline Operator (管道操作符 |>) (Stage 2) ​

允许以流式方式链式调用函数，提高代码可读性。

javascript
// 提案语法
const result = "hello"
  |> doubleSay
  |> capitalize
  |> (str => str + "!");

4. Records & Tuples (Stage 2) ​

引入不可变的数据结构：Record #{} (类似对象) 和 Tuple #[] (类似数组)，它们按值比较而非按引用比较。
