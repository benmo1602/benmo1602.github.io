# ES10 (2019) 模块

ECMAScript 2019 (ES10) 于 2019 年 6 月正式发布。本次更新主要集中在数组和字符串处理能力的增强，以及一些语法上的便利性改进。

## 发布内容 (Released Features)

以下是 ES2019 正式包含的新特性：

### 1. `Array.prototype.flat()` 和 `flatMap()`

这两个方法大大简化了数组扁平化的操作。

- **`flat(depth)`**: 按照指定的深度递归遍历数组，并将所有元素与遍历到的子数组中的元素合并为一个新数组返回。默认深度为 1。
- **`flatMap(callback)`**: 首先使用映射函数映射每个元素，然后将结果压缩成一个新数组。它等同于 `map` 后跟 `flat(1)`，但效率更高。

```javascript
const arr = [1, [2, [3, 4]]];

console.log(arr.flat());      // [1, 2, [3, 4]]
console.log(arr.flat(2));     // [1, 2, 3, 4]
console.log(arr.flat(Infinity)); // 深度无限

const sentences = ["Hello world", "Bye world"];
// 将每个句子拆分成单词并铺平
console.log(sentences.flatMap(x => x.split(" "))); 
// ["Hello", "world", "Bye", "world"]
```

### 2. `Object.fromEntries()`

这是 `Object.entries()` 的逆操作。它接收一个键值对列表（如 `Map` 或二维数组），并将其转换为一个对象。

```javascript
const entries = [['name', 'Bob'], ['age', 25]];
const obj = Object.fromEntries(entries);

console.log(obj); // { name: 'Bob', age: 25 }

// 配合 map 转换对象
const object = { x: 42, y: 50 };
const result = Object.fromEntries(
  Object.entries(object).map(([key, val]) => [key, val * 2])
);
console.log(result); // { x: 84, y: 100 }
```

### 3. `String.prototype.trimStart()` 和 `trimEnd()`

用于去除字符串开头或结尾的空白字符。为了与 `padStart`/`padEnd` 保持一致，标准推荐使用这两个名称，但浏览器也保留了 `trimLeft()` 和 `trimRight()` 作为别名。

```javascript
const str = "   Hello World   ";

console.log(str.trimStart()); // "Hello World   "
console.log(str.trimEnd());   // "   Hello World"
```

### 4. 可选 Catch 绑定 (Optional Catch Binding)

允许在 `try...catch` 块中省略 catch 的错误参数。如果你不需要使用错误对象，这会让代码更简洁。

```javascript
// 旧写法
try {
  // ...
} catch (error) { // 必须声明 error，即使不用
  // ...
}

// 新写法
try {
  // ...
} catch {
  // 忽略错误详情
  console.log('An error occurred');
}
```

### 5. `Symbol.prototype.description`

提供了一个只读属性 `description`，用于获取 Symbol 对象创建时的描述字符串。

```javascript
const sym = Symbol('my description');

// 旧写法
console.log(String(sym)); // "Symbol(my description)"

// 新写法
console.log(sym.description); // "my description"
```

### 6. `Function.prototype.toString()` 修订

要求 `toString()` 返回函数定义的源代码的精确切片，包括空格和注释。

```javascript
function /* comment */ foo() {}

console.log(foo.toString()); // "function /* comment */ foo() {}"
```

### 7. JSON 超集 (JSON Superset)

允许段落分隔符 (`U+2029`) 和行分隔符 (`U+2028`) 直接出现在字符串字面量中，而无需转义。这使得 JSON 字符串可以直接作为 JavaScript 字符串字面量使用。
