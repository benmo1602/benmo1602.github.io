# ES12 (2021) 模块

ECMAScript 2021 (ES12) 于 2021 年 6 月正式发布。本次更新带来了一些非常实用的字符串处理方法、逻辑赋值操作符以及新的 Promise 组合器。

## 发布内容 (Released Features)

以下是 ES2021 正式包含的新特性：

### 1. `String.prototype.replaceAll()`

在 ES12 之前，如果想替换字符串中**所有**出现的子串，必须使用带有全局标志 (`g`) 的正则表达式。`replaceAll` 方法提供了一种更直观的方式来替换所有匹配项。

```javascript
const str = "I love apple, apple is good.";

// 旧写法 (只替换第一个)
console.log(str.replace("apple", "orange")); 
// "I love orange, apple is good."

// 旧写法 (正则)
console.log(str.replace(/apple/g, "orange")); 
// "I love orange, orange is good."

// 新写法
console.log(str.replaceAll("apple", "orange")); 
// "I love orange, orange is good."
```

### 2. 逻辑赋值操作符 (Logical Assignment Operators)

引入了三个新的赋值操作符，结合了逻辑运算和赋值运算，使代码更加简洁。

- **`||=` (逻辑或赋值)**: 仅当左侧为假值 (falsy) 时赋值。
- **`&&=` (逻辑与赋值)**: 仅当左侧为真值 (truthy) 时赋值。
- **`??=` (空值合并赋值)**: 仅当左侧为 `null` 或 `undefined` 时赋值。

```javascript
let a = 0;
let b = 1;
let c = null;

// ||= 
a ||= 10; // a 是 0 (falsy)，所以 a 变为 10
b ||= 10; // b 是 1 (truthy)，所以 b 保持 1

// &&=
let x = 1;
x &&= 2; // x 是 1 (truthy)，所以 x 变为 2

// ??=
c ??= 20; // c 是 null，所以 c 变为 20
let d = 0;
d ??= 20; // d 是 0 (非 null/undefined)，所以 d 保持 0
```

### 3. `Promise.any()`

`Promise.any()` 接收一组 Promise 实例，只要其中的**一个** promise 成功 (fulfilled)，它就返回那个已经成功的 promise。如果所有的 promises 都失败 (rejected)，它会返回一个 `AggregateError`（一种包含所有错误的新错误类型）。

它与 `Promise.race()` 的区别在于，`race` 会在第一个 promise 敲定（无论成功或失败）时就返回，而 `any` 会忽略失败，直到遇到第一个成功。

```javascript
const p1 = new Promise((_, reject) => setTimeout(() => reject('Error 1'), 100));
const p2 = new Promise((resolve) => setTimeout(() => resolve('Success 2'), 200));
const p3 = new Promise((resolve) => setTimeout(() => resolve('Success 3'), 300));

Promise.any([p1, p2, p3])
  .then(value => console.log(value))
  .catch(error => console.log(error));

// 输出: "Success 2" (忽略了 p1 的失败，返回最先成功的 p2)
```

### 4. 数字分隔符 (Numeric Separators)

允许在数字字面量中使用下划线 `_` 作为分隔符，以提高大数字的可读性。这不会影响数值本身。

```javascript
const budget = 1_000_000_000; // 10亿
const bytes = 0xFF_0C_00_FF;  // 十六进制
const binary = 0b1010_0001;   // 二进制

console.log(budget === 1000000000); // true
```

### 5. `WeakRef` 和 `FinalizationRegistry`

这两个是高级内存管理特性，通常用于库的作者或特定的性能优化场景。

- **`WeakRef`**: 允许你保留对另一个对象的“弱引用”，而不会阻止该对象被垃圾回收 (GC)。
- **`FinalizationRegistry`**: 允许你在对象被垃圾回收时请求一个回调。

```javascript
let target = { value: 42 };
const weakRef = new WeakRef(target);

// ... 在某个时刻 ...
const deref = weakRef.deref();
if (deref) {
  console.log(deref.value);
} else {
  console.log("对象已被垃圾回收");
}
```
