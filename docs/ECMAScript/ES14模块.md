# ES14 (2023) 模块

ECMAScript 2023 (ES14) 于 2023 年 6 月正式发布。本次更新主要侧重于数组操作的不可变性（Immutability）增强，以及一些实用的便利性功能。

## 发布内容 (Released Features)

以下是 ES2023 正式包含的新特性：

### 1. 非破坏性数组更新 (Change Array by Copy)

这是 ES14 最重要的一组特性。引入了四个新的数组方法，它们在操作数组时**不会修改原数组**，而是返回一个新的副本。这对于 React、Redux 等依赖不可变数据的场景非常友好。

#### `toSorted()`
对应 `Array.prototype.sort()`，但返回排序后的新数组。

```javascript
const numbers = [3, 1, 4, 1, 5];

// 原地排序 (修改原数组)
// numbers.sort();

// 非破坏性排序 (返回新数组)
const sorted = numbers.toSorted();

console.log(sorted);  // [1, 1, 3, 4, 5]
console.log(numbers); // [3, 1, 4, 1, 5] (保持不变)
```

#### `toReversed()`
对应 `Array.prototype.reverse()`，但返回反转后的新数组。

```javascript
const items = ['a', 'b', 'c'];
const reversed = items.toReversed();

console.log(reversed); // ['c', 'b', 'a']
console.log(items);    // ['a', 'b', 'c']
```

#### `toSpliced(start, deleteCount, ...items)`
对应 `Array.prototype.splice()`，但返回修改后的新数组。

```javascript
const months = ['Jan', 'Mar', 'Apr', 'May'];

// 在索引 1 处插入 'Feb'
const newMonths = months.toSpliced(1, 0, 'Feb');

console.log(newMonths); // ['Jan', 'Feb', 'Mar', 'Apr', 'May']
console.log(months);    // ['Jan', 'Mar', 'Apr', 'May']
```

#### `with(index, value)`
用于替换指定索引处的元素，相当于 `arr[index] = value` 的非破坏性版本。

```javascript
const arr = [1, 2, 3];
const newArr = arr.with(1, 200);

console.log(newArr); // [1, 200, 3]
console.log(arr);    // [1, 2, 3]
```

### 2. 从尾部查找 (findLast / findLastIndex)

在 ES14 之前，如果想查找数组中的最后一个满足条件的元素，通常需要先反转数组或手动计算索引。现在可以直接使用 `findLast` 和 `findLastIndex`。

- **`findLast(callback)`**: 从数组末尾开始查找，返回第一个满足条件的元素。
- **`findLastIndex(callback)`**: 从数组末尾开始查找，返回第一个满足条件的元素的索引。

```javascript
const numbers = [5, 12, 50, 130, 44, 50];

// 查找最后一个大于 40 的数字
const lastLarge = numbers.findLast(n => n > 40);
console.log(lastLarge); // 50 (数组末尾的那个 50)

// 查找最后一个大于 40 的数字的索引
const lastIndex = numbers.findLastIndex(n => n > 40);
console.log(lastIndex); // 5
```

### 3. Symbol 作为 WeakMap 的键

在此之前，`WeakMap` 的键（Key）必须是对象（Object）。ES14 放宽了这一限制，允许使用唯一的 `Symbol` 作为键。这有利于创建更私有的键，且更容易被垃圾回收。

```javascript
const weak = new WeakMap();
const key = Symbol('my-ref');

weak.set(key, 'ES14 Feature');

console.log(weak.get(key)); // 'ES14 Feature'
```

### 4. Hashbang (Shebang) 语法支持

正式将 Hashbang (`#!`) 语法标准化。这允许在 JavaScript 文件的第一行指定解释器，主要用于编写 CLI 脚本。

```javascript
#!/usr/bin/env node

console.log('这个脚本可以直接作为可执行文件运行');
```

虽然 Node.js 早就支持这一特性，但现在它成为了 ECMAScript 语言标准的一部分，意味着在浏览器等其他环境中，JS 引擎也会正确地忽略这一行注释，而不会报错。
