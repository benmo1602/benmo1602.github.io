# ES11 (2020) 模块

ECMAScript 2020 (ES11) 于 2020 年 6 月正式发布。这是一个功能非常丰富版本，引入了许多开发者期盼已久的特性，如可选链、空值合并和 BigInt 等，极大地提升了 JavaScript 的开发体验。

## 发布内容 (Released Features)

以下是 ES2020 正式包含的新特性：

### 1. 可选链操作符 (Optional Chaining `?.`)

允许读取位于连接对象链深处的属性值，而不必明确验证链中的每个引用是否有效。如果链中的任何引用是 `null` 或 `undefined`，表达式将短路并返回 `undefined`。

```javascript
const user = {
  profile: {
    name: 'Alice'
  }
};

// 旧写法：容易报错或写得很长
// const city = user && user.address && user.address.city;

// 新写法
const city = user?.address?.city; 
console.log(city); // undefined (不会报错)

const name = user?.profile?.name;
console.log(name); // 'Alice'

// 也支持函数调用
user.nonExistentMethod?.();
```

### 2. 空值合并操作符 (Nullish Coalescing Operator `??`)

当左侧的操作数为 `null` 或 `undefined` 时，返回其右侧操作数，否则返回左侧操作数。这与逻辑或操作符 (`||`) 不同，`||` 会在左侧为假值（如 `0`、`''`、`false`）时也返回右侧操作数。

```javascript
const count = 0;

// 使用 ||
console.log(count || 10); // 10 (因为 0 是假值)

// 使用 ??
console.log(count ?? 10); // 0 (只有 null/undefined 才返回 10)

const message = "";
console.log(message ?? "Default"); // ""
console.log(message || "Default"); // "Default"
```

### 3. `Promise.allSettled()`

接收一组 Promise 实例，并在所有给定的 promise 都已“敲定”（即要么 fulfilled，要么 rejected）后返回一个 promise。结果是一个对象数组，每个对象描述每个 promise 的结果。

```javascript
const p1 = Promise.resolve('Success');
const p2 = Promise.reject('Error');

Promise.allSettled([p1, p2]).then(results => {
  console.log(results);
});

/* 输出:
[
  { status: 'fulfilled', value: 'Success' },
  { status: 'rejected', reason: 'Error' }
]
*/
```

### 4. BigInt

`BigInt` 是一种内置对象，它提供了一种方法来表示大于 `2^53 - 1` 的整数。这原本是 JavaScript 中 `Number` 能够表示的最大安全整数。

```javascript
// 在整数末尾添加 n
const bigNum = 9007199254740991n; 

// 或者使用构造函数
const bigNum2 = BigInt(9007199254740991);

console.log(bigNum + 1n); // 9007199254740992n

// 注意：BigInt 不能与 Number 混合运算，需要显式转换
// console.log(bigNum + 1); // TypeError
```

### 5. 动态 Import (`import()`)

允许以函数形式动态加载模块。该函数返回一个 Promise。这对于按需加载（Code Splitting）非常有用。

```javascript
const btn = document.getElementById('btn');

btn.addEventListener('click', async () => {
  const module = await import('./utils.js');
  module.doSomething();
});
```

### 6. `globalThis`

提供了一个标准的方式来获取不同环境下的全局 `this` 对象（在浏览器中是 `window`，在 Node.js 中是 `global`，在 Web Workers 中是 `self`）。

```javascript
console.log(globalThis); // 在任何环境下都能指向全局对象
```

### 7. `String.prototype.matchAll()`

返回一个包含所有匹配正则表达式的结果及分组捕获组的迭代器。比 `match()` 提供更多信息。

```javascript
const str = 'test1test2';
const regex = /t(e)(st(\d?))/g;

for (const match of str.matchAll(regex)) {
  console.log(match);
  // 返回完整的匹配详情，包括索引和捕获组
}
```
